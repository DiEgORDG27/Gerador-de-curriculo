# ✒️ CV Elite Pro - Gerador de Currículos Profissionais

Este projeto foi desenvolvido para facilitar a criação de currículos modernos com edição em tempo real e exportação otimizada para PDF. É uma ferramenta prática focada em design limpo e eficiência.

## 🚀 Tecnologias e Organização
Para demonstrar boas práticas de desenvolvimento, o código foi separado em módulos específicos:
* **HTML5**: Estrutura semântica do gerador.
* **CSS3**: Estilização com Flexbox/Grid e Media Queries exclusivas para impressão A4.
* **JavaScript (ES6+)**: Lógica de manipulação do DOM e interatividade em tempo real.

## 💡 Funcionalidades
- **Preview Instantâneo**: Veja as mudanças no layout enquanto preenche os dados.
- **Modo Dark/Light**: Interface adaptável para melhor conforto visual durante a edição.
- **Gerenciador de Competências**: Adição dinâmica de Hard e Soft Skills.
- **Exportação Otimizada**: Botão dedicado para gerar o PDF final formatado.

## 🛠️ Como Executar
1. Clone este repositório.
2. Abra o `index.html` em qualquer navegador moderno.
3. Preencha seus dados e clique em **GERAR PDF FINAL**.
